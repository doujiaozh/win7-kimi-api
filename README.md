## 为什么做这个

现代 AI 工具默认假设你有 Mac / Win11 / 最新手机。
但还有大量设备在运行 WinXP、Win2000、Android 4……
它们不该被 AI 时代抛弃。

这个项目记录：如何在老设备上跑通现代 AI。

## 已复活

| Windows 7 | ✅ | [win7](./win7) |
| Windows XP | ✅ | [winxp](./winxp) |
| Windows 2000 | ✅ | [win2000](./win2000) |
| Windows 98 | ✅ | [win98](./win98) |
| Windows 3.1 | ✅ | [win31](./win31) |
| DOS 6.22 | ✅ | [dos](./dos) |
| Android 4+ | ✅ | [android](./android) |

## 每个方案的共同点

- 用最少的资源（不依赖 GPU、不依赖新系统）
- 全部开源、可复制
- 记录所有踩过的坑
